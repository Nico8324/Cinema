# Security Policy

## Supported Versions

Cinema is under active pre-1.0 development. Security fixes are applied to the
latest release on `main` only; older tagged versions are not backported.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's private reporting:

1. Go to the [Security tab](../../security/advisories) of this repository.
2. Click **"Report a vulnerability"** to open a private advisory.

Include as much detail as you can: affected platform/OS version, steps to
reproduce, and potential impact. You should expect an initial response within
a few days. If the issue is confirmed, a fix will be prioritized and a
security advisory published once it's resolved.
